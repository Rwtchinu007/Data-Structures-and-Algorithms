# Data Structures and Algorithms (Java)

A practice repository of Java programs covering core data structures, algorithms, and problem-solving patterns.

## Repository Structure

- `Arrays/` - array basics, sorting, subarray problems
- `Basics/` - beginner math and pattern programs
- `Bit Manipulation/` - binary tricks and bitwise operations
- `HashMap/` - frequency counting and map-based problems
- `LeetCode/` - interview-style and LeetCode practice questions
- `Linked List/` - linked list creation and operations
- `Math/` - number theory and mathematical utilities
- `Queue/` - queue implementations
- `Recursion/` - recursive problem solving
- `Stack/` - stack implementations
- `Strings/` - string manipulation problems

## Prerequisites

- Java JDK 8+ installed
- PowerShell (Windows) or any terminal

Check Java version:

```powershell
java -version
javac -version
```

## How to Compile and Run

Most files contain a `main` method and can be compiled/run individually.

### 1) Open terminal at repository root

```powershell
cd "d:\Data-Structures-and-Algorithms"
```

### 2) Go to a folder and compile a file

Example:

```powershell
cd "Arrays"
javac MaxSubArray.java
```

### 3) Run the class

```powershell
java MaxSubArray
```

## Notes

- Folder names like `Bit Manipulation` and `Linked List` include spaces, so keep them inside quotes in terminal commands.
- File names must match class names for `public` classes in Java.
